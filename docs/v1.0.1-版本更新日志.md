# SeedAI v1.0.1 版本更新日志（2026-07-24）

> 里程碑：产物版本化 + 需求文档可下载 + UI 历史版本精确点选。
> 前序版本：v1.0.0（Agent/Skill 全局重构收尾）。

## 一、背景（用户原始问题）

用户问：「需求文档.txt 有没有上传到云存储，以及后续每次调整优化对应的修改呢？」

经代码核查确认：
- 需求文档**未传 COS**，仅存于 MySQL `projects.requirement_doc`（JSON）。
- 站点 HTML 在 DB `artifacts` 表**逐版留痕**（每次新插一行），但**云存储 key 写死 `/1/`**，每次生成**覆盖**上一版对象。
- 前端同名 `index.html` 在文件树里 `find(f => f.name === name)` 命中首条，**只能点第一条**，历史版本不可达。

→ 三项改进「全做」。

## 二、① COS key 版本化（后端 AI 核心，不再覆盖历史）

调用链：`proxy.py` 算版本号 → `GenerateReq.version` → `queue.py` job dict → `run_skill(**extra_kwargs)` → `generate_stream` → `_deliver`。

- `backend/ai_service/app/main.py`：`GenerateReq` 新增 `version: int | None = None`，并透传进 job dict。
- `backend/ai_service/app/core/queue.py`：取出 `version`，随 `user_id`/`project_id` 一并传入 `run_skill`。
- `backend/ai_service/app/skills/agent_generate_site.py` 与 `agent_build.py`：
  - `_deliver(html, trace_id, user_id=None, project_id=None, version=None)` 签名扩展。
  - COS key 改为 `previews/{user_id}/{project_id}/v{version}/index.html`；`version` 缺省降级用 `trace_id` 保证唯一，彻底解决覆盖。

## 三、② 需求文档可下载（后端 business + 前端）

- `backend/business/app/projects.py`：新增 `GET /api/projects/{project_id}/requirement-doc`，返回 `text/plain` 的 `.txt` 附件（JSON 文档 `ensure_ascii=False` 格式化）。
- `backend/business/app/schemas.py`：`ProjectResp` 加 `requirement_doc: str | None`，供前端重载后还原右侧「📋 需求文档」条目。
- `frontend/src/types.ts`：`Project` 接口加 `requirement_doc?: string | null`。
- 前端入口：
  - `frontend/src/components/RightPanel.vue`：需求文档条目加 `⬇` 下载按钮（Blob 触发下载）。
  - `frontend/src/views/ChatView.vue`：产物流卡片 / 方案确认卡片的需求文档条目加 `⬇` 下载按钮。
  - 两者统一 `downloadReqDoc()`：fetch 后端端点 → 生成 Blob → 触发浏览器下载。

## 四、③ 前端文件列表版本标签 + 精确点选历史版本

`frontend/src/components/RightPanel.vue`：
- `selectedFile` → `selectedArtifactId` / `selectedName` 双键定位。
- `selectFile` 重载：支持 `(artifactId: number, name?: string)` 精确点选，兼容旧 `(name: string)` 调用。
- 文件树 `allFiles` 加 `artifactId` + `version = idx + 1`，展示 `vN` 徽标。
- `currentFile` 按 `artifactId + name` 精确匹配（修复同名 `index.html` 只能点首条）。
- 点击文件调用 `selectFile(f.artifactId, f.name)` 精确联动右侧预览。

`frontend/src/components/MessageBubble.vue`：
- 气泡内建站产物文件标签由 `<span>` 改为 `<button>`，`@click` 发射 `open-file` 事件。
- `ChatView.vue` 监听 `@open-file="(name) => openArtifact(name, 'file')"`，联动右侧预览面板（task #247 收尾接线）。
