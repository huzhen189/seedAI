# v1.0.5 版本更新日志 — 生成结果以「文字 + 文件」形式返回

## 背景
用户反馈：生成文档时后台只返回了文件（HTML），没有返回文字说明。需要在返回文件的同时，对本次生成结果做一个汇总，以「文字 + 文件」形式呈现。

## 改动

### 后端 `backend/ai_service/app/skills/agent_generate_site.py` / `agent_build.py`（对称）
- 新增 `_build_generation_summary(plan, review, url, version, project_id, intent)`：组装本次生成的 Markdown 文字汇总，包含
  - 站点标题与类型（网站 / 互动小游戏）；
  - 目标（goal）；
  - 本次构建（规划步骤数、设计方向 mood/visual_strategy、交付产物 index.html）；
  - 质量评审（通过/优化、综合分、各维度 correctness/completeness/readability/compliance/efficiency/**craft**）；
  - 评审备注；
  - 交付与查看（在线预览地址、右侧预览面板/下载、历史版本按 `vN` 切换）；
  - 友好的「如需调整告诉我方向」收尾。
- `_parse_plan` 顺带带上 `design_spec`（首次生成即可在汇总中展示设计方向）。
- 收尾（resume 实际生成分支）：在 `_deliver` + `preview` 之后、`node stage="done"` 之前，`yield ev("refined", data=summary)`，让后端以文字形式返回汇总。

### 后端 `backend/ai_service/app/core/queue.py`
- L2 通用 `refined`（用流式 HTML 精炼助手文本）原本对 `agent_build` / `agent_generate_site` 也会触发，且排在 skill 事件之后（done 前），会用 HTML 精炼结果覆盖掉 skill 发的高质量汇总。
- 改为**仅对产出自然语言正文的技能**（`agent_chat` / `orchestrator`）启用通用精炼；建站类改由 skill 自身 emit 结构化 `refined`（本次生成结果汇总）。

### 前端（无需改动）
- 既有 `chat.ts` 已注册 `refined` 监听 → `onRefined` 覆盖助手气泡正文；`MessageBubble.vue` 对助手纯文本用 `MarkdownView` 渲染。汇总文案为 Markdown，自动排版展示。
- 文件侧仍由 `artifact-summary-card`（「✅ 生成完成 · 共 N 项产物」）与右侧预览面板呈现 → 实现「文字 + 文件」。

## 验证
- 后端 `py_compile` 全 OK（3 文件）；前端无改动（既有 `refined`/`MarkdownView` 通道复用）。

## 部署注意
需重启 `7102` AI 核心（skill 发 `refined` 汇总 + `queue.py` 精炼范围收敛）。重启后重新生成一次：助手气泡会出现 Markdown 文字汇总，文件以产物卡片 + 右侧预览呈现。
