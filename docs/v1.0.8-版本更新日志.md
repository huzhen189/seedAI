# v1.0.8 版本更新日志 — 修复「按我刚说的需求生成网站」未达预期

> 发布日期：2026-07-24
> 提交：`2641772`（本地，未 push）
> 标签：`v1.0.8`
> 关联诊断：`docs/诊断-生成网站未达预期-rc1-rc4.md`

## 一、背景

用户实测：在对话里先说「本地生活指南，首页天气，列表美食推荐，点开看地图定位，风格热闹活力」（真实需求），
再发「按照我刚刚的要求给我生成一个网站」，结果生成的网站完全不对——用首条天气闲聊编造了「深圳天气美食」，
且最终 `output=0 字符`，根本没建站。

经逐文件通读 + 日志实锤，定位为 **4 个根因叠加（RC1–RC4）**，与 v1.0.7 的死亡路由是不同问题。

## 二、根因与修复

### RC1（最致命）— 建站技能从不读取对话真实需求
- **现象**：`agent_build.py` / `agent_generate_site.py` 的 `generate_stream` 中，Planner 只取 `first_user_msg`（首条消息），
  `requirement_doc` / `conversation_summary` 虽被 `queue.py`/`runner.py` 一路透传，却在 `**kwargs` 处被吞掉、从未使用。
- **修复（F1）**：
  - `generate_stream` 新增显式参数 `requirement_doc: Optional[dict]` 与 `conversation_summary: Optional[str]`。
  - 新增 `_select_requirement()`：按 **结构化需求文档 → 对话摘要 → 最近含需求语义的用户消息（按内容丰富度排序，排除纯指令句如「帮我做个网站」）** 选优，返回 `(text, source)`。
  - 将选出的 `req_text` 注入 `first_user_msg`（供 RAG / Planner 使用）与 Coder 的 `【用户原始需求(来源: ...)】` 消息。
  - 结构化文档优先用 `report` 字段（PM 级 Markdown 长文），无则 `_req_doc_to_text()` 序列化为可读文本。

### RC2 — 整站意图被错误降级为单页
- **现象**：`intent/context.py` 关键词兜底把「首页/列表/页」匹配成「页面制作」，在 `_aggregate` 中把语义 `build/site` 覆盖成 `build/page`（单页）。
- **修复（F2）**：`pipeline._aggregate` 的上下文修正块加护栏——当 `final = build/site`、修正目标为 `page`、且**当前用户消息含整站关键词**（网站/官网/站点/建站/门户/整站/主页/首页）时，跳过该降级，保留用户明确表达的整站意图。

### RC3 — 死亡路由把整站请求打回需求分析
- **现象**：v1.0.7 死亡路由 `skill == agent_generate_site and not has_requirement_doc → agent_requirement`，即便修正 RC2 走整站仍会被打回。
- **修复（F3）**：`pipeline._aggregate` 新增 `has_conversation_requirement`（对话中存在同时含 build 关键词 + 内容关键词的用户消息即 `True`，说明用户已描述过具体需求）；`tools.run_tools` 死亡路由条件放宽为 `not has_requirement_doc and not has_conversation_requirement`——对话已描述需求即放行建站。

### RC4 — 方案暂停后不进 Coder，用户感觉「啥也没发生」
- **现象**：build skill Planner 后直接 `paused` + `return`，且 `paused` 事件缺 `cta_label`/`content`，用户无明确下一步。
- **修复（F4）**：build skill 的 `paused(await_confirm)` 补 `cta_label="确认并生成"` + `content` 咨询语（对齐 `agent_requirement.py` 的写法）。前端 `ChatView.onPaused` 已读取这两个字段并渲染 CTA 卡片（`alc-build-btn` → `startBuild()` → `resumeFromPlan`），**无需前端改动**。

## 五、端到端效果（复现 conv=4）

1. 用户发「首页天气 + 附近美食 + 地图定位（风格热闹活力）」。
2. 用户发「按照我刚刚的要求给我生成一个网站」。
3. 意图分类：`build/site`（F2 防降级）。

6. 用户点击 → 续跑进 Coder → 生成整站（首页天气 / 美食列表 / 地图定位，热闹活力风格）。
