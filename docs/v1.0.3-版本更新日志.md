# v1.0.3 版本更新日志

> 发布日期：2026-07-24
> 主题：需求文档返回原始生成内容 + 开发与样式设计 Agent 全面 premium 化

## 一、需求文档下载补齐「原始生成内容」（raw 落库 + 拼入文件）

**背景**：用户反馈下载的需求文档只有结构化内容、显得单调；而 `[需求] [3/4] 解析LLM输出 raw` 日志里的模型原始输出并未返回。

**改动**：
- `backend/ai_service/app/skills/agent_requirement.py`：在 `yield requirement_doc` 前增加 `data["raw_llm_output"] = raw`，将模型原始输出持久化进需求文档（随 `requirement_doc` 存入 `projects` 表）。
- `backend/business/app/projects.py`：下载端点 `GET /api/projects/{id}/requirement-doc` 在有 `raw_llm_output` 时拼入返回内容——report 分支追加 `## 原始生成内容（模型原始输出）` 代码块，JSON 分支保持原样（含 raw 字段）。下载文件不再是单调的结构化文本。

## 二、开发 + 样式设计 Agent 升级为「高级感」premium 标准

**改动**（两个生成 Agent 对称修改：`agent_generate_site.py` 与 `agent_build.py`）：

1. **SYS_PLANNER 新增 `design_spec`**：要求规划阶段产出高级视觉规格——`mood`(调性) / `visual_strategy`(差异化视觉策略) / `layout`(布局骨架) / `motion`(动效纲领) / `typography`(字号层级策略)。该字段通过 Planner 的原始 JSON 字符串自动透传给 Coder（`需求规格:\n{spec}`），**无需改转发代码**。
2. **SYS_CODER 升为「顶级前端创意开发工程师」**，并写入 8 条硬标准：玻璃拟态、柔和分层阴影、渐变光晕/微噪点、克制留白、编辑级排版、磁吸/抬升微交互、IntersectionObserver 滚动渐显、仅 transform/opacity 动画(60fps, 尊重 reduced-motion)、响应式断点、`:root` CSS 变量主题化、语义化+aria、真实内容(禁 lorem/灰块)。
3. **SYS_CODER_GAME** 增加视觉打磨要求（发光粒子 / HUD / 流畅帧率 / 赛博配色）。
4. **SYS_REVIEWER** 升级为「资深前端评审 + 设计总监」，新增第 6 维评分 **`craft`（视觉/交互精致度）**。
5. **INDUSTRY_DESIGN** 全部行业约束升级为高级视觉方向（玻璃拟态、渐变遮罩、磁吸 CTA、悬浮微交互、滚动 Logo 墙等）。
6. **`_review` 评分聚合同步支持 `craft`**：聚合列表加 `"craft"`，两处静态兜底分（缺 `<html>` / 标签未闭合）与最终静态通过分均补 `craft` 维。下游 `repair.py` 用 `len(scores)` 做均分分母，加维安全。
