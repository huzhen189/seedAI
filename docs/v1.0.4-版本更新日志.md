# v1.0.4 版本更新日志 — 需求文档统一 Markdown + 右侧预览支持 .md

## 背景
用户反馈下载的「活力生活圈.txt」扩展名与内容格式不匹配（有 `.txt` 也有 `.md`），并希望右侧预览页支持 `.md` 文件渲染。

## 改动

### 后端 `backend/business/app/projects.py`
- `GET /api/projects/{id}/requirement-doc` 下载端点**统一返回 Markdown（`.md`）**：
  - 含 `report` 字段 → 用 PM 报告正文；
  - 否则（旧格式 / 无 report）→ 新增 `_doc_to_markdown()` 把结构化文档字典转成可读 Markdown（品牌/目标用户/页面结构/功能清单/设计风格/色值）；
  - `raw_llm_output`（模型原始输出）始终一并拼接在 `## 原始生成内容` 代码块；
  - 文件名固定 `requirement_doc_{id}.md`，`media_type=text/markdown`。

### 前端 `frontend/src/components/RightPanel.vue`
- `previewMode()` 新增 `'md'` 分支（`.md` / `.markdown` 扩展名）；
- 新增 `mdContent` ref + `watch`：`.md` 文件优先用内联 `content`，否则按 `url` 拉取文本；
- 预览区新增 `<div class="pv-md">` 分支，用 `MarkdownView` 渲染 `mdContent`（复用 `marked` + DOMPurify）；
- `downloadReqDoc()` 文件名与 Blob 类型统一为 `.md` / `text/markdown`；需求文档树条目标签 `.txt` → `.md`。

### 前端 `frontend/src/views/ChatView.vue`
- 两处需求文档下载按钮（`asc-dl` / `alc-dl`）的 `downloadReqDoc()` 同步为 `.md` / `text/markdown`；tooltip 文案 `.txt` → `.md`。

## 验证
- 后端 `py_compile` OK；
- 前端 `vue-tsc -b` EXIT=0。

## 部署注意
需重启 `7101` 业务（下载端点统一 .md）+ `7100` 前端（右侧 .md 渲染）。历史项目的需求文档无论是否已含 `report`，下载均为 `.md`；`.md` 产物文件在右侧预览页可直接渲染。
