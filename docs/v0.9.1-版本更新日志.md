### 二、向量化升级（Chroma embedding 真因修复 + 质量提升）

- **根因**：原 `chroma.py _ef()` 在 `qwen_embedding_key` 为空时退回 `DeepSeek OpenAIEmbeddingFunction(model='deepseek-chat')`，但 **DeepSeek 无 embedding 端点** → 调 `/v1/embeddings` 返回 404，被 Chroma 包装成 `404 in query/upsert`，RAG/记忆静默降级（聊天仍 200）。
- **修复**：删除 DeepSeek embedding 分支；优先 Qwen `text-embedding-v3`，**`api_base` 用 `settings.qwen_base_url`（私有 MaaS / DashScope 兼容端点），不再硬编码 dashscope**；无 key 时本地 `SentenceTransformer(all-MiniLM-L6-v2)` 兜底。
- **启用**：`.env` 新增 `QWEN_EMBEDDING_KEY`（复用 Qwen 大模型 key）。远端 Chroma（1.12.219.195:7000）8 集合已用 Qwen ef 删除重建，端到端验证 `upsert + query + where` 通过（dim=1024）。

### 三、重置后集合结构确定性重建

- 新增 `ensure_collections()`：用统一 `_ef()` `get_or_create` 全部 8 集合（`components` / `memory` / `cache_gen` / `user_preferences` / `project_memory` / `project_code` / `error_patterns` / `conversation_context`）。
- AI 服务 `lifespan` 启动即调用 → **每次重启 7102 确定性重建向量库结构**（无论是否先重置）。
- `find_relevant_messages` 改 `get_or_create_collection`，消除“重置后集合还没建就被抢先读”的顺序依赖 404。

### 四、前端

- **#239 主题切换 light/dark/system**：`composables/theme.ts`（偏好持久化 + 跟随系统）+ `style.css` 暗色覆盖与过渡 + `main.ts` 早初始化防首屏白闪 + `TopNav.vue` 三段式切换控件。
- **AdminView 类型修复**：`types.ts` 的 `MetricsSnapshot` 对齐后端 `/admin/metrics` 真实结构（`model_usage` 改为 `{tokens,count,est_cost,raw_count}` 对象、`api_latency` 补 `LatencyBucket`）；删未用计算属性。`vue-tsc` 类型检查 **0 错误**。
