## v0.9.0 · 2026-07-23
**AI 核心流程重构 + 记忆四层 + Chroma 六集合**
- AI 流程升级：Planner→Coder→Reviewer 各阶段结构化 6 维自评；新增 `core/repair.py` 修复闭环（失败阶段定位 + best-of-N + ≤3 轮/30s）；闲聊低分轻量重答；`done` 钩子链串起 QC→精炼→蒸馏→代码索引→git 提交。
- 记忆四层：L0 MySQL `Message` 完整对话；L1 Redis `summary` 滚动摘要（1 天 TTL，过期回源 MySQL 重压）；L2 done→LLM 精炼→改写 `Message.content`→`refined` 事件；L2+ 蒸馏→`project_memories`+Chroma；L3 Chroma `user_preferences`+`User.card_json`。
- Chroma 六集合：`conversation_context`/`user_preferences`/`project_memory`/`project_code`/`error_patterns`/`components`，按 `conv_id`/`user_id`/`project_id` 隔离，20 条 HTML/CSS 错误种子。
- 修复预埋 Bug：`HttpClient(base_url=...)` 在 chromadb 1.5.9 无效→改用 host/port（修复前向量检索静默回退关键词兜底）。
- 统计补齐 `analytics.py`（repair/distill/code_index/refine/chat_retry/summary_fallback，Redis `an:v090:*`）。
