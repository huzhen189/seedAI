# 回归测试用例清单（15 条语句 + 2 交互场景）

> 测试环境：前端 `http://localhost:7100`，后端 `http://localhost:7101`（新代码 b37bf80 + 已 reset 干净库）
> 测试方式：浏览器打开 7100 手动逐条发送，边测边反馈「哪条 + 实际现象 + 预期」
> 每条约=预期意图/路由/SOP 角色 + 重点观察信号（对照：流程阻塞/遗漏/异常/内存上下文/意图/路由/拆分/状态机）

## 单意图（#1–#12）

### #1 `你好`
- **预期**：闲聊 → `agent_chat`，短回复，快速 `done`
- **观察**：是否秒回、有无多余子任务/编排

### #2 `用通俗的话解释一下什么是闭包`
- **预期**：解释类 → `agent_chat`，`done`
- **观察**：上下文是否正确（连续对话引用上文）

### #3 `把『Hello World』翻译成中文`
- **预期**：翻译 → `agent_chat`/doc，输出中文，`done`
- **观察**：输出是否真是翻译而非闲聊

### #4 `对比一下 React 和 Vue 的优缺点`
- **预期**：技术对比 → `agent_chat`，`done`
- **观察**：是否结构化对比、有无逻辑错误

### #5 `帮我做一个个人博客网站`
- **预期**：建站 → `agent_generate_site`（**dev 角色**）
- **观察**：① 是否先弹「执行计划」卡（plan_preview）；② 顶部 **SOP 四角色阶段条**是否高亮 dev；③ 是否真出建站产物

### #6 `帮我设计一个简洁的登录页面`
- **预期**：设计 → `chat_design`/`agent_design`（**design 角色**）
- **观察**：SOP 阶段条是否高亮 **design**

### #7 `帮我把刚才的博客网站改成深色主题`
- **预期**：迭代修改 → `build_modify`（**dev 角色**）
- **观察**：① 是否复用上文上下文（记得 #5 的博客）；② 若上下文不足是否会 `clarify` 而非静默失败

### #8 `帮我写一份产品需求文档，关于一个待办事项应用`
- **预期**：强信号 → `build_requirement`（**product 角色**，出 PRD）
- **观察**：SOP 是否高亮 **product**，产物是否为需求文档

### #9 `我想做一个电商网站，要有商品列表页和购物车功能`
- **预期**：建站带需求 → `agent_generate_site`（**dev**）
- **观察**：拆分是否合理（列表页/购物车是否作为子任务）

### #10 `帮我做一个猜数字的小游戏`
- **预期**：游戏 → `build_game`（**dev**），`done`
- **观察**：是否产出可运行游戏

### #11 `检查这段代码有没有问题：def add(a,b): return a+b`
- **预期**：代码评审 → `build_review`（**qa 角色**）
- **观察**：SOP 高亮 **qa**，评审是否点出「无类型校验/无文档」等

### #12 `这段 Python 报错 TypeError: list index out of range，帮我修：x=[1,2]; print(x[5])`
- **预期**：修 bug → `build_fix`（**qa 角色**），`done`
- **观察**：是否给出修复 + 解释越界原因

## 多意图编排（#13–#14）

### #13 `帮我生成一个公司官网，并写一篇关于我们公司的介绍文章`
- **预期**：双意图（建站 + 文档）→ 命中「并」→ **orchestration ≥ 2 子任务**，最后 merge
- **观察**：① 是否拆成 2 个 subtask；② 状态机是否完善（running→done）；③ 是否出合并结果；④ SOP 阶段条是否两个角色都走过

### #14 `给我做一个待办网站，再帮我写使用说明文档，顺便搜索一下同类产品`
- **预期**：三意图（建站 + 文档 + 搜索）→ **orchestration 3 子任务**
- **观察**：拆分是否合理、是否并行/分层、有无子任务卡死或遗漏

### #15 `删除我的项目`

- **观察**：① 是否弹确认/拦截而非直接执行；② 前端是否给出安全提示

## 交互场景（单独测）

### #16 取消级联（测 §6 B + §6 D）
- **语句**：`帮我做一个完整的在线教育平台，要有课程列表、详情页、购物车和支付`
- **操作**：发完后**等子任务开始跑**，立刻点前端的「取消」按钮
- **预期**：收到 `cancel_summary`（取消摘要卡），未跑的子任务变 `skipped`、进行中的变 `cancelled`，**无静默断开/无 500**
- **观察**：① 取消摘要卡是否渲染（列出 取消/已完成/未执行）；② 子任务泳道状态是否正确；③ 有无异常

### #17 断点续跑 G5（测 §6 E 修复）
- **语句**：`帮我做一个个人作品集网站`
- **操作**：若流程在「确认/await_confirm」暂停 → 点「继续/确认」按钮（resume）
- **预期**：应**真正重新执行**（而非只回放旧流不重跑）
- **观察**：续跑后 Coder 是否真的重新生成产物

## 反馈时重点告诉我这几类信号
- 🚫 **流程阻塞**：某条卡住不动 / 永远不 `done` / 子任务卡 running
- ⚠️ **异常未处理**：红字报错 / 500 / 连接断开无提示 / 超时无兜底
- 🧠 **上下文/内存**：该记住的忘了、长对话是否上下文错乱或明显膨胀
- 🎯 **意图/路由**：识别的意图或路由的 skill 跟预期不符
- 🧩 **拆分/状态**：多意图拆得不合理、子任务状态错乱（比如取消却显示 failed）
